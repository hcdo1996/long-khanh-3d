# Công viên Tượng đài Chiến thắng Long Khánh 3D

A walkable, third-person 3D model of the Victory Monument park in Long Khánh, Đồng Nai, Vietnam. It runs in the browser (three.js r128); open `index.html` through a web server or GitHub Pages.

This is a hand-built approximation made from reference photos. It is not a scan or a survey, and the surrounding shophouses, signs, food carts and people are fictional.
